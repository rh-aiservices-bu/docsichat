# docsichat

Documentation site powered by [Docsify](https://github.com/docsifyjs/docsify) v5.

- Browse the sidebar, or jump straight to the [Guide](guide.md).
- Edit any Markdown file in `docs/` and refresh — no build step.

## Local preview

```bash
python3 -m http.server 3000 --directory docs
# then open http://localhost:3000
```
