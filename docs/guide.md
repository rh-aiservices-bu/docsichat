## Writing pages

Each `.md` file in `docs/` becomes a route: `guide.md` is served at `#/guide`.

## Adding pages

1. Create `docs/mypage.md`.
2. Link it from `_sidebar.md`.

## Configuration

Docsify is configured in `docs/index.html` under `window.$docsify` — see the [configuration reference](https://docsify.js.org/#/configuration).
