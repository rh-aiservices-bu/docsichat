# Configuration

Configure the connection to your API. Values are stored in this browser only.

<div id="api-config-form"></div>

## Saved configuration

| Setting | Value |
| --- | --- |
| API Endpoint | <span class="api-config" data-field="endpoint"></span> |
| API Key | <span class="api-config" data-field="key"></span> |

The API key preview shows the first 6 characters (or `eyJ…` for JWT-shaped keys) followed by a mask. To change it, replace it in the form above — the full key is never displayed. To start over, click **Clear** in the form; it removes both the saved endpoint and key.
